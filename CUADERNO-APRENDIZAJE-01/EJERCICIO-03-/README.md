# Ejercicio 03 - Ficha de perfil

## Qué he aprendido
- A crear una ficha de perfil
- A organizar estadísticas con flexDirection: 'row'

## Respuesta a la pregunta de comprensión
Si quieres que dos estadísticas aparezcan una al lado de otra, ¿en qué View aplicarías `flexDirection: 'row'` y por qué?

Respuesta: Lo aplicaría en la que agrupa las dos estadísticas, en este caso styles.stats

## Qué he modificado
- App.tsx para mostrar el avatar, el nombre, la profesión y las estadísticas
- He añadido estilos para presentar la información dentro de una tarjeta y colocar las estadísticas en horizontal.

## Resultado
La interfaz muestra una tarjeta de perfil centrada con la foto del usuario, su profesión y dos estadísticas
