# Ejercicio 05 - Tarjeta de producto

## Qué he aprendido
- A combinar imagen, textos y un botón para crear una tarjeta de producto
- A organizar elementos en una fila con flexDirection: 'row' y justifyContent: 'space-between'.

## Respuesta a la pregunta de comprensión
¿Qué información debería tener mayor jerarquía visual: categoría, nombre del producto o precio? Justifica tu decisión.

Respuesta: El precio puede tener la mayor jerarquía porque es un dato clave

## Qué he modificado
- App.tsx para crear una tarjeta con imagen, categoría, nombre del producto, valoración, precio y botón para añadirlo
- He utilizado tamaños de texto, colores

## Resultado
Una tarjeta blanca con una imagen en la parte superior y, debajo, la categoría, el nombre, su valoración y el precio. Al final aparecen el precio y el botón de añadir
