# Ejercicio 01 - Mi primera pantalla

## Qué he aprendido
- A crear una pantalla con React Native
- A organizar y centrar elementos con estilos

## Respuesta a la pregunta de comprensión
Explica con tus palabras la diferencia entre el componente `View` y el componente `Text`.

Respuesta: `View` sirve como contenedor para agrupar y organizar elementos de la interfaz. `Text` se utiliza para mostrar texto en pantalla y aplicarle estilos.
