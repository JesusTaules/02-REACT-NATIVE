# Ejercicio 08 - Catálogo con FlatList

## Qué he aprendido
- A mostrar una colección de datos con FlatList en lugar de escribir cada tarjeta por separado
- A definir una lista de productos, mostrarla en dos columnas y usar una clave única para cada elemento

## Respuesta a la pregunta de comprensión
¿Qué ventaja tiene cambiar un producto en el array en lugar de buscar su tarjeta manualmente dentro del JSX?

Respuesta: Al cambiar el producto en el array, la lista se actualiza a partir de los datos

## Qué he modificado
- App.tsx para crear un catálogo con seis productos y mostrarlo mediante FlatList
- He configurado dos columnas y he usado el identificador de cada producto como clave

## Resultado
La interfaz muestra el título Productos y un catálogo desplazable con seis tarjetas organizadas en dos columnas. Cada tarjeta incluye un icono, el nombre del producto y su precio.
