# Ejercicio 04 - Pantalla de acceso

## Qué he aprendido
- A montar visualmente una pantalla de acceso con TextInput, Pressable y Text.
- A dar formato a los campos, al botón y al texto de registro mediante estilos.

## Respuesta a la pregunta de comprensión
¿Por qué en este ejercicio no necesitamos todavía `useState`?

Respuesta: Porque solo se muestra el formulario y no se necesita leer, guardar ni validar datos

## Qué he modificado
- App.tsx para incluir un mensaje de bienvenida, campos de correo y contraseña, un botón de inicio de sesión y un texto para registrarse.
- He aplicado estilos para distinguir los campos y el botón.

## Resultado
La interfaz muestra una pantalla de acceso sobre fondo blanco, con dos campos de entrada, un botón de INICIAR SESIÓN y un mensaje para registrarse
