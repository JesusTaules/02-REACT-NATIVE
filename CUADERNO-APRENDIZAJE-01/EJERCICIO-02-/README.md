# Ejercicio 02 - Tarjeta de bienvenida

## Qué he aprendido
- A construir una tarjeta
- A usar padding, márgenes, bordes redondeados y colores

## Respuesta a la pregunta de comprensión
¿Por qué usarías `padding` en una tarjeta en lugar de `margin` para separar el texto del borde?

Respuesta: porque padding crea espacio dentro de la tarjeta y margin crea espacio fuera

## Qué he modificado
- App.tsx para crear una tarjeta de bienvenida

## Resultado
La interfaz presenta una tarjeta blanca centrada sobre un fondo gris azulado. Incluye el mensaje ¡Bienvenido!, una descripción y un botón azul con el texto COMENZAR.
